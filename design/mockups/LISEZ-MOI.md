# Maquettes Spesa Sporta (format .dc.html)

Fichiers issus de l'outil de design. Ils ne sont pas du code de production : à lire comme des références.
- Valeurs de style en ligne (px, couleurs, rayons) = vérité visuelle.
- Logique d'état = bloc `<script type="text/x-dc">` en bas de chaque fichier.
- Balises propres à l'outil : `<x-dc>`, `<helmet>`, `{{trou}}`, `<sc-for>`, `<sc-if>`. Ne pas les recopier : réimplémenter dans la pile de l'app.
- Le fichier `support.js` appelé par les maquettes n'est pas fourni : sans importance pour la lecture.
- En cas d'écart avec ../DESIGN.md, DESIGN.md prévaut.
Index des fichiers : DESIGN.md, section 14.
